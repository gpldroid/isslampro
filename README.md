# إسلام برو

موقع قرآني عربي يعمل مباشرة من المتصفح، بواجهة عربية من اليمين إلى اليسار، ومهيأ للهواتف والحواسيب. يعتمد هذا المستودع على **GitHub Pages** لاستضافة الملفات الثابتة.

**الموقع:** https://gpldroid.github.io/isslampro/

## محتويات الموقع

- القرآن الكريم والمصحف والتلاوات.
- القراء والتفسير والمكتبة المرئية.
- مواقيت الصلاة وأدوات الأذان.
- إذاعات القرآن والبث الصوتي.
- الأذكار والمحتوى الإسلامي والبحث.
- حفظ بعض الاختيارات محلياً في المتصفح.
- دعم التثبيت كتطبيق ويب تقدمي (PWA) والتخزين المؤقت عبر Service Worker.

قد تحتاج التلاوات المباشرة وبعض البيانات والخدمات إلى اتصال بالإنترنت. التخزين المؤقت لا يعني أن جميع وظائف الموقع تعمل دون اتصال.

## النشر على GitHub Pages

المشروع موقع ثابت؛ لا يحتاج إلى Node.js أو npm أو خطوة build.

1. افتح **Settings → Pages** في مستودع GitHub.
2. من **Build and deployment** اختر **Deploy from a branch**.
3. اختر الفرع `main` والمجلد `/(root)`.
4. احفظ الإعدادات وانتظر اكتمال النشر.
5. افتح https://gpldroid.github.io/isslampro/

ملف `index.html` الموجود في جذر المستودع هو الصفحة الرئيسية. عند تحديث الملفات ودفع Commit إلى الفرع المنشور، يعيد GitHub Pages نشر الموقع تلقائياً.

## ملفات المشروع الأساسية

| الملف أو المجلد | الوظيفة |
| --- | --- |
| `index.html` | الصفحة الرئيسية وبيانات الموقع الوصفية |
| `style.css` | التنسيق والتصميم |
| `app.js` | منطق التطبيق والتفاعلات |
| `prayer-calc.js` | حساب مواقيت الصلاة |
| `data/` | ملفات البيانات |
| `img/`, `icons/`, `fonts/` | الصور والأيقونات والخطوط |
| `manifest.webmanifest` | إعدادات تثبيت الموقع كتطبيق ويب |
| `sw.js` | التخزين المؤقت ودعم الاستخدام عند انقطاع الاتصال |
| `robots.txt`, `sitemap.xml` | إرشادات وفهرسة محركات البحث |
| `.nojekyll` | منع معالجة Jekyll لملفات الموقع |

## المسارات والروابط

هذا الموقع منشور كـ **Project Pages** داخل المسار `/isslampro/`، وليس على نطاق المستخدم الجذري. لذلك:

- استخدم المسارات النسبية للملفات المحلية، مثل `style.css` و`app.js` و`icons/icon-192.png`.
- اترك `start_url` و`scope` في ملف manifest متوافقين مع مجلد المشروع.
- يجب أن تشير الروابط الأساسية وبيانات المشاركة إلى `https://gpldroid.github.io/isslampro/`.
- عند إضافة ملفات محلية جديدة، اختبر مساراتها من رابط الموقع المنشور، لا من جذر النطاق فقط.

## ملاحظات الصيانة

- حافظ على أسماء الملفات ومجلداتها الحالية ما لم تكن هناك حاجة فعلية لتغييرها.
- بعد تعديل ملفات JavaScript أو CSS، حدّث أرقام إصدارات الاستدعاء والتخزين المؤقت عند الحاجة حتى لا يحتفظ المتصفح بنسخ قديمة.
- لا تضع مفاتيح API أو كلمات مرور أو بيانات سرية في ملفات الموقع؛ كل ما يُنشر هنا يمكن للزوار الاطلاع عليه.
- لا يتطلب النشر سير عمل لاستيراد ملفات من مستودع آخر؛ مصدر الموقع هو الملفات الموجودة في هذا المستودع.
