# ألترا قرآن | Ultra Quran

منصة قرآنية عربية تعمل مباشرة من المتصفح، بواجهة عربية واتجاه RTL، ومهيأة للهواتف والحواسيب ويمكن تثبيتها كتطبيق ويب تقدمي (PWA).

**رابط الموقع:** https://gpldroid.github.io/isslampro/

## المزايا

- القرآن الكريم والمصحف والتصفح بين السور والآيات.
- مكتبة التلاوات والقراء.
- مواقيت الصلاة وأدوات الأذان.
- إذاعات القرآن والبث الصوتي.
- مكتبة المواد المرئية والمحتوى القرآني.
- الأذكار والمحتوى الإسلامي والبحث.
- حفظ العناصر المفضلة محلياً في المتصفح.
- واجهة متجاوبة، ودعم التثبيت كتطبيق ويب.
- عامل خدمة (Service Worker) لتخزين واجهة التطبيق وبعض البيانات والموارد التي تمت زيارتها، بما يساعد على الاستخدام عند انقطاع الاتصال. البث المباشر وبعض الخدمات الخارجية تحتاج إلى الإنترنت.

## التشغيل والنشر

المشروع ثابت ولا يحتاج إلى خطوة بناء أو مدير حزم:

1. افتح إعدادات المستودع ثم **Settings → Pages**.
2. اختر **Deploy from a branch**.
3. حدد الفرع `main` والمجلد `/(root)` ثم احفظ.
4. افتح https://gpldroid.github.io/isslampro/ بعد اكتمال النشر.

الملف `index.html` في جذر المستودع هو نقطة الدخول. ملفات CSS وJavaScript والبيانات والصور والخطوط موجودة محلياً ضمن المستودع.

## بنية المشروع

- `index.html`: واجهة الموقع والبيانات الوصفية.
- `style.css`: التصميم والتجاوب.
- `app.js`: منطق التطبيق والواجهات.
- `prayer-calc.js`: حسابات مواقيت الصلاة.
- `data/`: بيانات القرآن والمكتبة والقراء والإذاعات.
- `icons/`, `img/`, `fonts/`: الأيقونات والصور والخطوط.
- `manifest.webmanifest`: إعدادات تثبيت تطبيق الويب.
- `sw.js`: التخزين المؤقت ودعم العمل عند ضعف الاتصال.

## التحديثات

ملف GitHub Actions في `.github/workflows/sync-upstream.yml` يستورد محتويات مجلد `docs/` من المشروع المرجعي عند تشغيل سير العمل. بعد الاستيراد تُعاد مواءمة الروابط مع نطاق هذا المستودع.
